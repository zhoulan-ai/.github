# 周浪 Lan

[STRONG FLOW 純浪力量](https://strongflow.tw)共同創辦人。我們在台南經營兩間重量訓練與器械皮拉提斯工作室，從你現在的身體狀況開始，一對一陪你練。

工作室的營運，我一條一條交給 AI 協作：財務月結、行銷報表、每天的工作日報。做久了發現，真正有用的不是哪個工具，而是把自己的做事邏輯寫清楚，讓 AI 照著做。

這裡放的，是其中整理成公開版、任何工作室或小團隊都能直接拿去用的 Skill。
